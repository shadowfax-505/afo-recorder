Repeat the checks

For the extracted kit:

python3 host/check_package.py --out package-check.json
python3 host/run_tests.py
python3 host/convert.py breadboard/recording-example.afolog --out example-csv --no-plots

The test suite needs a C compiler named cc for one firmware contract test. CSV conversion and the package check need only Python. Preserve the kit manifest and your receipts; use new result paths rather than overwriting earlier evidence.

For the repository-level extraction and captured-UDP replay, run the download verifier from this variant's folder:

python3 design/verify_breadboard_download.py --python /path/to/test-python --out /path/to/new-results

Add --plot-python /path/to/plot-environment/bin/python to check plots as well. This verifier uses the preserved UDP capture in the full repository; that historical capture is not duplicated into the small lab kit. The receipt records whether plotting ran and whether Matplotlib was present in the CSV-test environment. Browser checks were performed separately against a loopback server restricted to local resources.
