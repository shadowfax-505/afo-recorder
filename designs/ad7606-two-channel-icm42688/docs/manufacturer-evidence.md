# Manufacturer evidence — reviewed 28 September 2026

- [ADS131M04 evaluation carrier](https://www.ti.com/lit/ug/sbau332a/sbau332a.pdf): J1–J4, J6, supply isolation, clock selection and input loading.
- [AD7606 original device](https://www.analog.com/media/en/technical-documentation/data-sheets/AD7606_7606-6_7606-4.pdf): Pin functions, serial mode, VDRIVE and input range; does not prove seller-module resistor population.
- [ESP32-S3 DevKitC-1](https://documentation.espressif.com/esp-dev-kits/en/latest/esp32s3/esp32-s3-devkitc-1/user_guide_v1.0.html): Header pin identities, exclusive power inputs and PSRAM restrictions; check received DevKit revision.
- [MIKROE-4237](https://www.mikroe.com/6dof-imu-14-click): mikroBUS pin map, 3.3 V and SPI jumper positions.
- [MIKROE-4237 schematic](https://download.mikroe.com/documents/add-on-boards/click/6dof_imu_14_click/6dof-imu-14-click-schematic-v100.pdf): Module internal circuit and interface jumpers.
- [MCP600x](https://ww1.microchip.com/downloads/en/DeviceDoc/MCP6001-1R-1U-2-4-1-MHz-Low-Power-Op-Amp-DS20001733L.pdf): Package pinout and operating limits; existing simulation uses a stated surrogate.
- [TPS63070](https://www.ti.com/lit/ds/symlink/tps63070.pdf): PCB buck-boost pin functions and application constraints.
- [TPS60150](https://www.ti.com/lit/ds/symlink/tps60150.pdf): PCB 5 V charge pump pin functions; Pololu bench module is a different power implementation.

Supplier photographs support visible terminal labels only. Received-board continuity, regulator identity, resistor population, waveforms and mechanical dimensions require inspection. No online source can establish those measurements for the actual unit.
