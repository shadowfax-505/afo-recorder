# Preserved earlier driver evidence

These original two-second synthetic results were produced with the pre-confirmation AD7606 driver and metadata identifying firmware revision 1.5. They remain unchanged as historical evidence. The current two-second results in the parent directory were regenerated against revision 1.6, which additionally rejects conversion pulses when BUSY never rises.

The preserved production source snapshot is [tested-source-1.5](../../../integrated-recorder/tested-source-1.5/). These old results do not establish a pass for the current driver. The original orchestration source was not separately snapshotted when this first short run was recorded.
