# Interface review — 28 September 2026

Project lead: Muttakin Rahman

## Release 15

The project library, guided build, detailed assembly workspace and compact-PCB preview now share a consistent visual system: warm neutral surfaces, graphite work areas, restrained orange accents, system typography and technical labels. All assets needed by the interface are local. The architecture illustration is an original SVG diagram, not a physical wiring drawing.

The library filters the six hardware configurations by ADC. The build guide separates preparation, connection, verification and result recording. The assembly workspace has a stage rail, searchable wire selector, tabbed inspector, viewport focus mode, keyboard controls and camera fitting based on scene bounds. F fits the scene, T selects top view, / focuses connection search, and Escape exits focus mode. Arrow keys move between inspector tabs. Mobile layouts move inspection below the viewport and expose a stage selector.

## Checks completed

- Browser interaction checks passed across all six configurations: all ten stage buttons, wire search and endpoint selection, locate connection/component, guide navigation and PCB loading/selection/reset.
- No JavaScript page errors were observed during the six-configuration test.
- Stage query parameters were preserved; guide next/previous navigation updates the stage rail and URL.
- Library filtering returned the expected two ADS131M04 configurations.
- Desktop and phone screenshots were inspected. Tested phone pages have no horizontal page overflow.
- Result save/reload and JSON download passed. The temporary test note was removed by restoring the browser's prior storage. No measured pass was entered.
- Local static navigation links were checked; a missing header-map link in the ADS131M04/ICM variant now points to that variant's module qualification guide.
- The independent physical-wiring data validator passed for all six variants. These are data checks, not continuity measurements.
- Package hashes and ZIP integrity are regenerated by the release script. Archived original ICM files are compared against their recorded hashes.

## Scope and limits

This release changes presentation and camera/navigation behavior. Circuit data, firmware, PCB layout and manufacturing outputs were not changed; no new firmware compilation or PCB design-rule checks are claimed. Physical power, signal quality, timing, battery and human-use validation remain pending. Existing manufacturer credits, provenance and third-party licence notices remain in place. Reference-asset redistribution limitations still apply to full project packages.

## Interaction update 16

Opening an individual board from the complete assembly now requires a double-click. Single-click wire and module inspection remains available. Browser checks confirmed single clicks retain the whole view and double clicks open a board in all six variants.
