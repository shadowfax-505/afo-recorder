# Firmware builds

See ../../docs/sd-card-wiring.md for the hardware-specific SD pin assignment. Select breadboard-record-* for GPIO47 and record-* for PCB GPIO38. Diagnostics do not mount SD. Physical operation is untested.

Profiles were rebuilt on 12 October 2026 (after the ported fixed-two 1.12 Wi-Fi preview fix) from firmware `dual-1.5`; each manifest lists the source hashes. Recording profiles hold no Wi-Fi password: read the per-device password from the USB console at first boot. Not flashed or simulated.
