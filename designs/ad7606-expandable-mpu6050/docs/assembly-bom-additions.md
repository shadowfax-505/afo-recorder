# Revision 12 assembly materials

Use 8 BusBoard BB830 boards: BB0, BB1, BB2, BB3, BB4, AUX1, AUX2, DIST1. Existing analog components retain their values. Auxiliary component values and orientations are in build-guide.html; count each component row once, not each wire endpoint. Add one Adafruit 1833 USB inlet and two 33 Ω inline resistors. Retain the selected regulators, adapters, protection devices, battery and modules. Use insulated jumper leads; solder local LDO capacitors and USB data wiring. These are laboratory fixtures, not additional custom PCBs.
