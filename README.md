# AFO Research Recorder

**Live site:** https://shadowfax-505.github.io/afo-recorder/

Start with [the project guide](documentation/start-here.md) or browse the live site. Locally, serve this directory with `python3 -m http.server 8769`.

**Complete packages:** [Download all six engineering packages](https://github.com/shadowfax-505/afo-recorder/releases/tag/v0.1.0). Large ZIP packages are release assets; the source and detailed viewer models are in this repository.

- **designs/** — six self-contained hardware/software packages, grouped by ADC, EMG capacity and IMU.
- **GitHub Releases** — full ZIP distribution of each named package (the local `downloads/` directory is not duplicated in Git history).
- **documentation/** — system overview, build sequence, acquisition instructions, validation status and project status.
- **design-catalog.json** — package inventory and source locations.

The original ICM packages remain unchanged outside this organized release. Work scripts, intermediate build caches and earlier archives remain in their existing workspace locations so ongoing tools and old links keep working. The release excludes Python caches and workstation-specific path text. Technical filenames required by build tools are retained.

No hardware measurements or participant data are presented as completed results. Manufacturer credits and source references are retained.
